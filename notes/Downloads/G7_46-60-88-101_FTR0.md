### **Expected Result and Discussion** 

##### **Evaluation plan** 

We plan to test on a governed holdout set of real tickets from our industry partner, with TF-IDF + Logistic Regression/Random Forest as the baseline for comparison. 

Metric 

Baseline target In-house SLM target 

Classification accuracy (Macro~72% (TF-IDF + Log-Reg) **≥ 0.85** F1) Routing accuracy Manual / static rules **≥ 80%** correct first-time assignment SLA compliance improvement 0% (baseline) **+15-20%** via automated escalations Inference latency (CPU) N/A (manual read) **< 5 seconds** per ticket 

**Hypothesis:** a fine-tuned SLM can learn this domain well enough to classify accurately, without the latency and privacy risks of calling a commercial LLM API.
